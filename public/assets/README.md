# Tài nguyên thương hiệu

Đặt logo MISA chính thức tại đây với tên **`misa-logo.png`** (nền trong suốt, ưu tiên chiều cao ≥ 80px).

- Header sidebar và màn đăng nhập sẽ tự động hiển thị logo này.
- Tính năng "Tạo thiệp chúc mừng" sẽ dùng chính file này làm ảnh tham chiếu để AI vẽ đúng logo lên thiệp.

Nếu chưa có file, ứng dụng vẫn chạy bình thường (chỉ hiển thị tên "MISA PR Workstation").
